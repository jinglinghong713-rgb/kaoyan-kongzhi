# kaoyan-kongzhi

考研**自动控制原理**错题分析 —— Claude Code skill。

按 S1-S6 闭环分析错题：

- 拆最小知识点（叶子级粒度）
- 查错题账本（命中报次数 + 历史）
- 归因（基础五类 + 控制专属错误类型）
- 双分支判定：A（真题错题，相似题仅非真题）/ B（普通错题，可含真题）
- 文件库相似题三阶梯（按相关性 + 难度分布）
- 按反馈更新掌握度（L0-L4）
- 归档、更新账本
